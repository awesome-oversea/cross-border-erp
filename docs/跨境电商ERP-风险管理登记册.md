## 1. 风险管理流程

```
风险识别 → 风险评估 → 风险应对 → 风险监控 → 风险关闭
```

---

## 2. 风险评估标准

### 2.1 概率等级

| 等级 | 概率 | 说明 |
|---|---|---|
| 1 | 低 | 发生可能性<20% |
| 2 | 中 | 发生可能性20%-50% |
| 3 | 高 | 发生可能性>50% |

### 2.2 影响等级

| 等级 | 影响 | 说明 |
|---|---|---|
| 1 | 低 | 影响单模块，不影响里程碑 |
| 2 | 中 | 影响多模块，可能影响里程碑 |
| 3 | 高 | 影响核心链路，影响里程碑 |

### 2.3 风险等级矩阵

| | 影响1 | 影响2 | 影响3 |
|---|---|---|---|
| 概率3 | 中 | 高 | 高 |
| 概率2 | 低 | 中 | 高 |
| 概率1 | 低 | 低 | 中 |

## 4. 风险监控

### 4.1 监控频率

| 风险等级 | 监控频率 |
|---|---|
| 高 | 每日站会跟踪 |
| 中 | 每周评审跟踪 |
| 低 | 每阶段评审跟踪 |

### 4.2 风险升级

- 高风险：立即升级至项目经理和产品负责人
- 中风险：周会讨论，必要时升级
- 低风险：阶段评审时确认

---

## 5. 风险回顾

每阶段里程碑评审时回顾风险登记册：
- 已关闭风险：确认应对有效
- 持续开放风险：评估是否需要调整应对策略
- 新增风险：识别和登记
