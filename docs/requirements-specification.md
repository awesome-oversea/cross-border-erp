# 跨境电商ERP — 需求规格说明书

> **文档定位**：本文档从业务视角阐述跨境电商ERP系统的功能需求、业务流程和核心能力覆盖，旨在展示对跨境电商全链路业务的理解深度。

---

## 1. 产品定位

面向跨境电商卖家的**全链路 SaaS ERP 平台**，覆盖从选品开发、店铺运营、广告投放、订单履约、供应链采购、仓储物流、财务核算到商业智能的完整业务闭环。

### 1.1 目标用户

| 角色 | 核心诉求 |
|------|---------|
| 运营人员 | 多平台店铺管理、Listing刊登与优化、广告投放管理、订单处理 |
| 采购人员 | 供应商管理、采购计划与执行、1688对接 |
| 仓库人员 | 入库/出库/质检/盘点、FBA发货 |
| 财务人员 | 成本核算、对账管理、利润分析 |
| 管理者 | 经营驾驶舱、KPI监控、决策分析 |

### 1.2 核心业务流程总览

```
选品开发 → 刊登运营 → 广告推广 → 订单处理 → 采购备货 → 仓储发货 → 物流追踪 → 客服售后 → 财务核算 → 经营分析
  (PDM)     (SOM)      (ADS)      (OMS)     (SCM)      (WMS)      (TMS)     (CRM)      (FMS)      (BI)
```

## 2. 业务域需求详述

### 2.1 IAM — 组织权限域

**需求背景**：跨境电商企业通常有多个运营团队、多个店铺、多个市场，需要灵活的组织架构和数据隔离。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 用户管理 | 用户CRUD、角色分配、多租户隔离 |
| 角色管理 | 角色定义、菜单权限+数据权限配置、对象级权限 |
| 岗位管理 | 岗位定义、岗位层级、岗位与部门关联 |
| 对象权限 | 产品/Listing/广告等业务对象的精细权限控制 |
| 10维数据权限 | 见架构设计文档§7.2 |

**业务流程**：
```
创建用户 → 分配角色 → 配置数据权限范围 → 用户登录 → 权限校验 → 数据过滤
```

---

### 2.2 PDM — 产品开发域

**需求背景**：跨境电商卖家的核心资产是产品。从选品调研到产品上架，需要完整的产品生命周期管理。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| SPU/SKU管理 | 产品主数据、多规格变体（母体/子体）、分类/品牌 |
| 产品生命周期 | DRAFT → 开发中 → ACTIVE → 下架 |
| 开发审核 | 新品开发流程、审批节点、审核意见 |
| 渠道SKU映射 | 产品SKU与平台SKU（ASIN/SKU）的映射关系 |
| 组合产品 | 捆绑销售、赠品策略 |
| 包材管理 | 产品包装规格、包装材料关联 |
| 产品问题记录 | 质量问题追踪、与CRM/WMS联动 |
| **AI选品** | 市场趋势分析、竞品数据聚合、智能选品推荐 |

**业务流程**：
```
选品调研 → 创建SPU → 维护SKU变体 → 开发审核 → 渠道SKU映射 → 上架
```

---

### 2.3 SOM — 销售运营域

**需求背景**：跨境电商需要在 Amazon、Shopify、TikTok 等多平台管理 Listing，需要统一的运营工具。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 店铺管理 | 多平台店铺授权（Amazon/Shopify/TikTok等）、连接状态监控 |
| Listing管理 | 多平台刊登、批量调价/促销、多语种翻译 |
| 价格规则 | Listing价格计算器、Buybox采集调价、自动调价规则 |
| Listing监控 | 销量/价格/Buybox/库存/评分异常监控、多渠道告警 |
| 运营日历 | 营销活动规划、平台活动报名 |
| **AI定价** | 基于竞争数据和销售趋势的自动定价建议 |

**业务流程**：
```
店铺授权 → Listing创建/同步 → 价格规则配置 → 运营监控 → 异常告警
```

---

### 2.4 ADS — 广告管理域

**需求背景**：亚马逊广告（SP/SB/SD/SBV）是卖家获取流量的核心手段，需要统一的广告管理和优化工具。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 广告活动管理 | SP/SB/SD/SBV四种广告类型、批量管理多店铺广告 |
| 广告组管理 | 关键词定向、商品定向、投放组管理 |
| 关键词管理 | 搜索词提炼、否定关键词、竞价调整 |
| 预算/竞价管理 | 批量更改状态/预算/竞价、自动调价规则 |
| 广告仪表盘 | ACoS/曝光/点击/转化/花费分析、分组分析视图 |
| **AI优化** | 广告策略优化建议、PMS集成智能调价 |

**业务流程**：
```
创建广告活动 → 设置广告组 → 添加关键词 → 配置竞价策略 → 投放优化 → 效果分析
```

---

### 2.5 OMS — 订单管理域

**需求背景**：订单是跨境电商的核心交易载体，涉及多平台订单导入、审核、履约、退款等复杂流程。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 订单三层模型 | 渠道订单 → ERP销售单 → 履约单/包裹单 |
| 平台订单同步 | Amazon/TikTok/Shopify等平台订单自动同步 |
| 批量导入 | Excel批量导入订单、历史订单迁移 |
| 订单审核 | 审核策略配置、风控校验、利润检测 |
| 拆单/合单 | 按仓库/物流/商品拆分、合并发货 |
| 有货先发 | 部分发货、分批出库 |
| 物流申报规则 | 海关申报信息自动生成 |
| 退款/退换货 | 全额退款、部分退款、退货入库 |
| 风险订单检测 | 异常订单拦截、黑名单管理 |
| **AI风控** | 基于历史数据的订单风险预测 |

**业务流程**：
```
订单导入 → 审核校验 → 拆分合并 → 发货履约 → 完成确认
  ↑                              ↓
  └── 退款/退换货 ←─────────────┘
```

---

### 2.6 SCM — 供应链域

**需求背景**：跨境电商的供应链涉及多供应商、多采购模式、跨仓备货，需要灵活的采购管理体系。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 供应商管理 | 供应商信息/联系人/资质/评分、禁用校验 |
| 供应商平台 | 供应商线上接单、订单确认、发货通知 |
| 五种采购模式 | 市场采购、工厂采购、天猫淘宝、1688、加工采购 |
| 采购审核流程 | 多级审批、自动审批、采购合同管理 |
| 跟单管理 | 订单跟踪、交期管理、进度更新 |
| 销单入库核对 | 采购单与入库单的自动核对 |
| 三仓备货分析 | 本地仓/FBA仓/海外仓的库存分布与备货建议 |
| 1688采购对接 | 1688商品搜索、下单、订单同步 |
| **AI补货** | 基于销量预测和安全库存的智能补货建议 |

**业务流程**：
```
采购需求 → 供应商选择 → 采购单创建 → 多级审批 → 采购执行 → 收货入库 → 对账结算
```

### 2.7 WMS — 仓储管理域

**需求背景**：仓储管理涉及收、发、存的全流程，需要精确的库存台账和严格的作业流程。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 仓库管理 | 仓库基础信息、区域/库位管理、库位分组统计 |
| 库存五态 | 在手、预占、可售、在途、不良五种状态 |
| 入库流程 | 收货 → 质检 → 上架（良品放行、次品冻结/退货/返修） |
| 出库流程 | 预留 → 拣货 → 打包 → 称重 → 发货 |
| 出货质检 | 出库前质量检查、抽检规则 |
| 库存调拨 | 仓库间调拨、调拨单跟踪 |
| 库存盘点 | 周期性盘点、循环盘点、差异处理 |
| Removal订单 | FBA退货处理、弃置订单 |
| 自定义标签 | 模板配置、条码打印 |
| **AI预测** | 基于历史数据的库存需求预测 |

**业务流程**：
```
入库流程：收货 → 冻结 → 质检 → 上架/不良处理
出库流程：预留 → 拣货 → 打包 → 称重 → 发货
库存管理：调拨 → 盘点 → 库存调整
```

---

### 2.8 FBA — 亚马逊物流域

**需求背景**：亚马逊FBA是跨境电商卖家的核心物流方式，需要独立的管理工具处理FBA库存和货件。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| FBA库存查看 | EFN/NARF库存查看、库龄分析、库存预警 |
| 补货建议 | 自定义日均销量/备货时效/去噪规则 |
| 备货购物车 | 多SKU批量加入、一键生成货件计划 |
| 货件计划管理 | 三种创建模式（同步Amazon/加载ID/先创建无ID） |
| 发货打包SOP | 装箱单、标签打印、FBA头程物流 |
| 五大异常处理 | 货件差异、接收差异、库存调整、赔偿、移除 |

**业务流程**：
```
库存监控 → 补货建议 → 货件计划 → 打包发货 → 追踪签收 → 库存更新
```

---

### 2.9 TMS — 物流运输域

**需求背景**：跨境电商涉及2000+物流渠道，需要统一的物流商管理和轨迹追踪能力。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 物流商管理 | 2000+物流渠道接入、API授权、运输方式管理 |
| 运费算法 | 运费模板配置、运费试算、批量修改 |
| 轨迹追踪 | 物流轨迹查询、上网时效分析、妥投统计 |
| 物流严选 | 物流商绩效对比分析、优选推荐 |
| **AI物流** | 物流商智能推荐、时效预测 |

**业务流程**：
```
物流商接入 → 运费配置 → 运单生成 → 轨迹追踪 → 签收确认 → 费用结算
```

**核心功能**：

|---------|---------|

| 工单管理 | 多平台邮件/消息管理、智能分配、状态流转 |


### 2.11 FMS — 财务管理域

**需求背景**：跨境电商财务核算复杂（多币种、多平台、多费用类型），需要自动化的成本归集和利润核算。

**核心功能**：

| 功能模块 | 需求描述 |
|---------|---------|
| 8类成本事件 | 采购/头程/仓储/佣金/广告/支付/尾程/其他 |
| 自动成本归集 | SCM收货→FMS联动、WMS发货→FMS联动、自动成本事件生成 |
| 异常成本检测 | 成本异常预警、归集差异分析 |
| 利润核算 | FIFO成本计算、多维度利润报表 |
| 对账管理 | 供应商对账、物流商对账、平台费用核对 |
| 应收/应付 | 应收账款确认、付款管理、账期管理 |
| 汇率管理 | 汇率快照化、多币种自动换算 |
| **AI成本归集** | 智能费用分类、成本异常检测 |

**业务流程**：
```
业务事件发生 → 成本事件自动生成 → 成本归集 → 利润核算 → 报表输出
```

## 3. 跨域业务流程

### 3.1 端到端销售履约流程（最核心链路）

```
1. PDM: 产品开发 → SKU创建 → 渠道SKU映射
2. SOM: Listing刊登 → 价格策略配置
3. ADS: 广告活动创建 → 投放优化
4. OMS: 订单导入 → 审核 → 拆合单 → 下发WMS
5. WMS: 库存预留 → 拣货 → 打包 → 发货
6. TMS: 物流单生成 → 轨迹追踪 → 签收
7. FMS: 收入确认 → 成本归集 → 利润核算
8. CRM: 售后处理（如有问题）
9. BI: 经营分析 → KPI评估
```

### 3.2 采购入库流程

```
OMS(销量数据) → SCM(补货建议 → 采购计划 → 审批 → 采购单)
  → WMS(收货 → 质检 → 入库)
    → FMS(采购成本事件自动生成)
    → SCM(销单核对)
```

## 4. 非功能需求

### 4.1 多租户

- 租户间数据完全隔离（Schema级别）
- 支持租户级配置和个性化
- 租户级流量控制和资源隔离

### 4.2 数据权限

- 10维数据权限控制
- 支持角色级、用户级、对象级权限配置

### 4.3 审计追溯

- 所有业务操作保留审计日志
- 关键操作（审核、审批、删除）记录操作人和操作时间

### 4.4 可靠性

- Outbox模式保证事件不丢失
- Saga模式保证跨域最终一致性
- 关键业务操作支持幂等重试

### 4.5 可扩展性

- 14个域可独立拆分部署
- 插件化连接器对接外部平台
- 业务规则可配置化
