## 1. 系统概述

跨境电商ERP是面向跨境卖家和多渠道品牌的经营中台型ERP系统，覆盖14个业务域，集成AI选品系统PMS，支持混合履约模式。

### 1.1 系统架构

- 14业务域：工作台/组织权限/产品开发/销售运营/广告管理/订单/供应链/仓储/FBA/物流/客服售后/财务/商业智能/系统设置
- 3个核心渠道：Amazon/Shopify/TikTok Shop
- AI辅助决策：选品/补货/广告/风控

### 1.2 用户角色

| 角色 | 主要操作 |
|---|---|
| 超级管理员 | 系统配置、权限管理 |
| 运营经理 | 渠道管理、Listing管理、价格策略 |
| 运营专员 | 订单处理、Listing维护、客服 |
| 采购经理 | 采购策略、供应商管理 |
| 仓储主管 | 库存管理、出入库、盘点 |
| 财务经理 | 结算审核、利润分析 |
| 客服专员 | 邮件处理、退款退货 |

## 2. 登录与权限

### 2.1 登录

1. 访问系统URL
2. 输入用户名和密码
3. 系统验证JWT Token
4. 根据角色跳转对应首页

### 2.2 权限说明

- 功能权限：基于角色的菜单和按钮权限
- 数据权限：基于10维度的数据可见范围
- 对象权限：特定业务对象的访问控制

## 4. 产品开发(PDM)

### 4.1 产品库管理

1. 新建产品：填写SPU信息→添加SKU→设置属性
2. 产品生命周期：开发中→试销→稳定→淘汰
3. SKU分层：爆款/主力/长尾/淘汰

### 4.2 AI选品

1. 查看PMS选品建议
2. 审批/拒绝建议
3. 审批通过后自动创建产品草稿

---

## 5. 销售运营(SOM)

### 5.1 店铺授权

1. 新增店铺：选择平台→OAuth授权→确认
2. 授权状态监控

### 5.2 SKU映射

1. 内部SKU→渠道SKU映射
2. 批量导入映射关系

### 5.3 Listing同步

1. 选择产品→选择店铺→同步Listing
2. 同步日志查看

---

## 6. 订单管理(OMS)

### 6.1 订单抓取

1. 系统自动定时抓取渠道订单
2. 手动触发抓取
3. 抓取日志查看

### 6.2 订单处理

1. 查看渠道订单→确认→生成ERP销售单
2. 拆单/合单操作
3. 风控校验结果查看

### 6.3 订单状态

待审核→已确认→已分配→已发货→已完成

---

## 7. 仓储管理(WMS)

### 7.1 库存查询

1. 按仓库/SKU查询库存
2. 查看五类状态：在手/预占/可售/在途/不良

### 7.2 入库操作

1. 采购收货→质检→入库
2. 入库单确认

### 7.3 出库操作

1. 订单分配→拣货→打包→发货
2. PDA扫码操作

### 7.4 盘点调拨

1. 创建盘点任务→执行盘点→差异处理
2. 创建调拨单→审批→执行

---

## 8. 供应链管理(SCM)

### 8.1 采购单

1. 新建采购单：选择供应商→添加SKU→设置数量和价格
2. 提交审核→审核通过→执行采购

### 8.2 AI补货

1. 查看PMS补货建议
2. 审批/拒绝建议
3. 审批通过后自动生成采购单草稿

## 12. 常见问题

| 问题 | 解决方案 |
|---|---|
| 订单抓取失败 | 检查店铺授权状态和API限流 |
| 库存数据不一致 | 查看库存事务账，确认是否有未完成操作 |
| Listing同步失败 | 检查SKU映射和平台API状态 |
| PMS建议未显示 | 检查PMS连接配置和Kafka消费状态 |
| 报表数据延迟 | 检查Flink任务状态和ClickHouse同步 |
