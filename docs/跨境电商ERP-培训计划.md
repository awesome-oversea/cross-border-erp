# 跨境电商ERP 培训计划

版本：V1.0
编制日期：2026-05-01
文档状态：正式发布

---

## 1. 培训目标

- 确保所有用户掌握跨境电商ERP核心操作
- 确保运维团队掌握系统部署和监控
- 确保开发团队掌握技术架构和开发规范

---

## 2. 培训对象与内容

### 2.1 业务用户培训

| 培训模块 | 对象 | 时长 | 内容 |
|---|---|---|---|
| 系统概览 | 全部用户 | 2小时 | 14域介绍、角色权限、基本操作 |
| 运营操作 | 运营经理/专员 | 4小时 | SOM/OMS/ADS操作、Listing管理、订单处理 |
| 采购操作 | 采购经理/专员 | 3小时 | SCM操作、采购流程、供应商管理 |
| 仓储操作 | 仓储主管/作业员 | 4小时 | WMS操作、PDA作业、盘点调拨 |
| 财务操作 | 财务经理/专员 | 3小时 | FMS操作、成本归集、利润分析、对账 |
| 客服操作 | 客服专员 | 2小时 | CRM操作、邮件管理、退款退货 |
| 管理看板 | 总经理/老板 | 2小时 | DASHBOARD/BI操作、KPI管理 |
| AI辅助决策 | 运营/采购/财务 | 2小时 | PMS建议查看、审批、反馈 |

### 2.2 运维团队培训

| 培训模块 | 时长 | 内容 |
|---|---|---|
| 系统架构 | 4小时 | 14域架构、DDD分层、事件驱动 |
| 部署运维 | 4小时 | K8s部署、CI/CD、环境管理 |
| 监控告警 | 3小时 | Prometheus/Grafana/Jaeger使用 |
| 灾备恢复 | 2小时 | 备份恢复、主从切换、全量恢复 |

### 2.3 开发团队培训

| 培训模块 | 时长 | 内容 |
|---|---|---|
| 技术架构 | 4小时 | Spring Cloud全家桶、DDD分层、事件驱动 |
| 开发规范 | 3小时 | 编码规范、API规范、数据库规范 |
| 测试规范 | 2小时 | 单元测试、集成测试、E2E测试 |
| 连接器开发 | 3小时 | 连接器接口、幂等重试补偿 |

---

## 3. 培训时间安排

| 阶段 | 时间 | 培训内容 |
|---|---|---|
| Phase 1结束 | 2026-06-05 | 开发团队培训（架构+规范） |
| Phase 4结束 | 2026-08-29 | 运维团队培训（部署+监控） |
| Phase 6第1周 | 2026-09-13 | 业务用户培训（系统概览+核心操作） |
| Phase 6第2周 | 2026-09-20 | 业务用户培训（专项操作+AI辅助） |

---

## 4. 培训方式

| 方式 | 适用场景 | 说明 |
|---|---|---|
| 现场培训 | 业务用户 | 面对面讲解+实操演练 |
| 在线培训 | 远程用户 | 视频会议+屏幕共享 |
| 文档自学 | 开发/运维 | 操作手册+技术文档 |
| 录播视频 | 全部用户 | 关键操作录屏存档 |

---

## 5. 培训验收

| 验收方式 | 适用对象 | 标准 |
|---|---|---|
| 实操考核 | 业务用户 | 独立完成核心操作流程 |
| 知识测试 | 开发/运维 | 正确率≥80% |
| 场景演练 | 全部 | 按角色完成指定场景 |
