# ADR-008: 前端技术选型

日期：2026-05-01
状态：已采纳
决策者：技术负责人

---

## 上下文

跨境电商ERP系统需要选择前端技术栈，支撑管理后台和PDA仓库作业。核心需求包括：
- 14域管理后台（复杂表单+数据表格+图表）
- PDA仓库作业（移动端扫码操作）
- 多角色权限前端实现
- 国际化支持（中英文）
- 高性能（P95≤2秒）

---

## 决策

采用 **Next.js 14+ App Router + React 18+ + TypeScript + Ant Design 5.x** 技术栈。

---

## 备选方案

### 方案A：Vue 3 + Element Plus

| 优点 | 缺点 |
|---|---|
| Element Plus企业级组件成熟 | SSR支持不如Next.js |
| 国内社区活跃 | TypeScript支持不如React生态 |
| 学习曲线平缓 | 大型项目状态管理复杂 |

### 方案B：React + UmiJS

| 优点 | 缺点 |
|---|---|
| 企业级框架 | 约束较多 |
| 插件体系丰富 | 社区活跃度下降 |
| 国内文档好 | App Router不支持 |

### 方案C：Next.js 14+ App Router（采纳）

| 优点 | 缺点 |
|---|---|
| App Router现代架构 | 学习曲线较陡 |
| SSR/SSG性能优势 | Ant Design SSR需配置 |
| React Server Components | 团队React经验需提升 |
| TypeScript生态最好 | 部署需Node.js运行时 |

---

## 理由

1. **App Router**：React Server Components减少客户端JS体积，首屏加载更快
2. **TypeScript**：14域接口类型安全，减少前后端联调错误
3. **Ant Design 5.x**：企业级组件库，表格/表单/图表组件丰富，适合ERP场景
4. **Next.js生态**：API Routes可做BFF层，统一后端API调用
5. **SSR性能**：管理后台首屏加载P95≤2秒目标更容易达成

---

## 技术栈详情

| 层级 | 技术选型 | 版本 | 用途 |
|---|---|---|---|
| 框架 | Next.js | 14+ | App Router + SSR |
| UI库 | React | 18+ | 组件化 |
| 类型 | TypeScript | 5.x | 类型安全 |
| 组件库 | Ant Design | 5.x | 企业级UI组件 |
| 状态管理 | Zustand | 4.x | 轻量全局状态 |
| 服务端状态 | SWR | 2.x | 数据请求缓存 |
| HTTP客户端 | Axios | 1.x | API请求 |
| 图表 | ECharts | 5.x | 数据可视化 |
| 表单 | Ant Design Form | 5.x | 表单验证 |
| 表格 | Ant Design Table | 5.x | 数据表格 |
| 权限 | 自研RBAC Hook | - | 前端权限控制 |
| 国际化 | next-intl | - | 中英文切换 |
| PDA | 响应式布局 | - | 移动端适配 |

## 影响

- 团队需学习Next.js App Router和React Server Components
- Ant Design 5.x SSR配置需注意
- 部署需Node.js运行时（不能用纯静态部署）
- PDA移动端通过响应式布局适配，不单独开发
