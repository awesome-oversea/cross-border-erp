# ADR-0001 模块化单体架构基线

## 决策

首期采用 Java 17 + Spring Boot 3 的模块化单体架构，按 dashboard、iam、pdm、som、ads、oms、scm、wms、fba、tms、crm、fms、bi、sys 十四个领域模块组织代码，由 erp-app 聚合启动。

## 原因

- 初期团队交付复杂跨域闭环，模块化单体降低分布式复杂度。
- 领域模块边界清晰，后续可按连接器、BI、工作流等外围能力拆分服务。
- 统一进程内事务更适合订单、库存、采购、财务基础闭环。

## 约束

- 领域模块不直接依赖其他领域模块内部实现。
- 跨域协作优先通过应用服务、领域事件或接口契约完成。
- 所有业务数据必须保留 tenantId、审计字段与可追踪来源。
