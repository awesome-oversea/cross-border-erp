# 跨境电商ERP 变更管理规范

版本：V1.0
编制日期：2026-05-01
文档状态：正式发布

---

## 1. 目的

规范跨境电商ERP项目开发过程中的需求变更、设计变更、技术变更和环境变更管理流程，控制变更对项目进度和质量的影响。

---

## 2. 变更分类

| 变更类型 | 定义 | 审批级别 | 示例 |
|---|---|---|---|
| A类-紧急变更 | 影响线上运行的紧急修复 | 技术负责人 | 线上Bug修复、安全漏洞修补 |
| B类-需求变更 | 新增/修改/删除业务需求 | 产品负责人+项目经理 | 新增报表、调整业务流程 |
| C类-设计变更 | 架构/数据库/API设计变更 | 技术负责人 | 新增接口、调整表结构 |
| D类-环境变更 | 基础设施/配置变更 | 运维负责人 | 服务器扩容、配置修改 |

---

## 3. 变更流程

### 3.1 标准变更流程

```
变更提出 → 影响评估 → 变更审批 → 变更实施 → 变更验证 → 变更关闭
```

### 3.2 紧急变更流程

```
变更提出 → 技术负责人口头审批 → 紧急实施 → 事后补录评估 → 变更关闭
```

### 3.3 需求冻结窗口

- Phase 4完成后进入需求冻结
- 冻结期间不接受新需求，仅接受A类紧急变更
- 新需求进入二期需求池

---

## 4. 变更评估

### 4.1 评估维度

| 维度 | 评估内容 |
|---|---|
| 范围影响 | 影响哪些域/模块/接口 |
| 进度影响 | 是否影响里程碑 |
| 质量影响 | 是否影响已测试功能 |
| 风险影响 | 是否引入新风险 |
| 工作量 | 预估人天 |

### 4.2 评估标准

| 影响等级 | 判定标准 | 审批要求 |
|---|---|---|
| 低 | 单模块内，不影响其他模块 | 模块负责人审批 |
| 中 | 跨2-3个模块，不影响里程碑 | 技术负责人+项目经理审批 |
| 高 | 跨4+模块或影响里程碑 | 项目组集体评审 |

---

## 5. 变更记录

### 5.1 变更登记表

| 字段 | 说明 |
|---|---|
| 变更编号 | CHG-YYYY-NNN |
| 变更类型 | A/B/C/D |
| 变更标题 | 简要描述 |
| 提出人 | 变更提出者 |
| 提出日期 | 变更提出时间 |
| 影响评估 | 范围/进度/质量/风险 |
| 审批人 | 审批者 |
| 审批结果 | 通过/拒绝/挂起 |
| 实施人 | 变更实施者 |
| 完成日期 | 实施完成时间 |
| 验证结果 | 通过/未通过 |

---

## 6. 变更控制措施

- 所有变更必须登记，无登记不变更
- 代码变更必须通过PR审查
- 数据库变更必须通过Flyway脚本
- 配置变更必须通过Nacos/Git管理
- 环境变更必须通过CI/CD流水线
