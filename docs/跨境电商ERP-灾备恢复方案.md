## 1. 灾备目标

| 指标 | 目标值 |
|---|---|
| RTO（恢复时间目标） | ≤4小时 |
| RPO（恢复点目标） | ≤1小时 |
| 系统可用性 | ≥99.5% |

---

## 2. 灾备等级定义

| 等级 | 场景 | 影响范围 | 恢复策略 |
|---|---|---|---|
| P0 | 数据库主库宕机 | 全系统不可用 | 主从切换，RTO≤30分钟 |
| P1 | 应用服务全部宕机 | 全系统不可用 | K8s自动重启+手动介入，RTO≤1小时 |
| P2 | Kafka集群故障 | 异步事件中断 | Broker切换，RTO≤1小时 |
| P3 | Redis集群故障 | 缓存失效，性能下降 | 主从切换+缓存预热，RTO≤30分钟 |
| P4 | ES集群故障 | 搜索功能不可用 | 节点恢复，RTO≤2小时 |
| P5 | 单域模块故障 | 该域功能不可用 | K8s自动重启，RTO≤15分钟 |

## 3. 备份策略

### 3.1 数据库备份

| 备份类型 | 频率 | 保留周期 | 存储位置 |
|---|---|---|---|
| 全量备份 | 每日 02:00 | 30天 | 异地对象存储 |
| WAL归档 | 实时 | 7天 | 本地+异地 |
| 基础设施配置 | 每次变更 | 90天 | Git仓库 |

### 3.2 应用备份

| 备份类型 | 频率 | 保留周期 |
|---|---|---|
| Docker镜像 | 每次构建 | 10个版本 |
| Helm Chart | 每次变更 | Git版本管理 |
| Nacos配置 | 每次变更 | Git版本管理 |
| Flyway脚本 | 每次变更 | Git版本管理 |

### 3.3 中间件备份

| 组件 | 备份策略 | RPO |
|---|---|---|
| Kafka | 多副本+跨Broker | 0（同步复制） |
| Redis | RDB+AOF | ≤1分钟 |
| ES | 快照+跨节点副本 | ≤1小时 |
| MinIO | 纠删码+跨节点 | 0 |

## 4. 灾备切换流程

### 4.1 数据库主从切换

```
1. 监控告警：主库健康检查失败
2. 确认故障：人工确认主库不可用
3. 执行切换：提升从库为主库
4. 更新配置：Nacos/应用更新数据库连接
5. 验证恢复：核心链路验证
6. 通知相关方：运维/开发/业务
```

### 4.2 应用服务恢复

```
1. K8s自动检测Pod异常
2. 自动重启Pod（最多3次）
3. 若自动恢复失败，人工介入
4. 检查日志定位根因
5. 修复后重新部署
6. 核心链路验证
```

### 4.3 全量恢复流程

```
1. 评估故障影响范围
2. 启动灾备环境（如需）
3. 恢复数据库（全量备份+WAL回放）
4. 恢复中间件（Kafka/Redis/ES）
5. 部署应用服务
6. 数据一致性验证
7. 核心链路验证
8. 通知业务方恢复
```
